# Tech Sales Market Analysis

## Project Title
Customer Segmentation and Product Preference Analysis for a Tech Company

## Project Overview
This project analyzes four years of sales data from a technology company to understand customer purchasing behavior and market trends. The analysis focuses on identifying which products are most preferred by different customer segments and how factors such as region, sales channel, and discounts influence purchasing decisions.

Power BI is used to create interactive dashboards that visualize key metrics including product performance, revenue distribution, and customer segmentation. The insights generated support data-driven business decision making.

---

## Dataset Description

The dataset represents simulated sales transactions for a technology company selling products such as:

- Laptops
- Smartphones
- Monitors
- Headphones
- Keyboards
- Wireless Chargers

**Time Period:** 4 Years  
**Records:** ~4000 transactions  
**Industry:** Technology / Electronics

### Dataset Fields

| Column | Description |
|------|-------------|
| Transaction ID | Unique identifier for each sale |
| Date | Date of the transaction |
| Product Name | Name of the product sold |
| Category | Product category |
| Quantity Sold | Number of units sold |
| Unit Price | Price per unit |
| Revenue | Total revenue from the sale |
| Region | Geographic region where the sale occurred |
| Customer Type | Individual, Corporate, Educational |
| Discount Applied (%) | Discount applied to the sale |
| Payment Method | Method used for payment |
| Sales Channel | Online, In-Store, Partner Distributor |

---

## Project Objectives

### 1. Identify Product Preferences
- Determine which products generate the highest revenue
- Analyze demand across product categories

### 2. Customer Segmentation
- Compare purchasing behavior between Individual, Corporate, and Educational customers
- Understand each segment's revenue contribution

### 3. Sales Channel Performance
- Analyze which channels generate the most revenue
- Compare Online, In-Store, and Partner Distributor sales

### 4. Regional Sales Performance
- Identify top performing regions
- Understand geographic market trends

### 5. Discount Impact
- Analyze how discounts influence purchasing behavior
